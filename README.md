# Knowledge Forge AI community resources

This repository maintains the organization’s public profile and default community
guidance. Visit [Knowledge Forge AI](https://www.knowledge-forge.ai/), the
[GitHub profile](https://github.com/Knowledge-Forge-AI), or
[Discussions](https://github.com/orgs/Knowledge-Forge-AI/discussions).

- `profile/README.md`: the public organization profile.
- `profile/assets/rei-ai.webp`: the original Rei Ai mascot illustration.
- `community/WELCOME.md`: maintained body of the existing welcome discussion.
- Contribution, license, conduct and security documents: organization defaults,
  superseded by repository-local guidance where provided.

GitHub renders supported Markdown/HTML and images. It does not expose an arbitrary
CSS theme for the organization or discussion board. The existing pinned welcome
card uses GitHub’s blue/mint palette; Rei appears in the profile and welcome body.
Changing this repository does not itself synchronize the welcome discussion.

Software and documentation use AGPL-3.0-or-later with separate commercial terms
where offered. The Rei illustration and organizational brand assets are excluded
from the AGPL grant; see NOTICE and BRAND-ASSETS.md. Upstream and third-party terms
remain intact. Contributions follow CONTRIBUTING.md and CLA.md, including the
explicit acknowledgment required there. Contact sam.lair@knowledge-forge.ai.
